# Social video references

Downloaded source videos and one reference frame per second. In each `frames/`
folder, `frame-0001.jpg` is approximately 0 seconds, `frame-0002.jpg` is 1
second, and so on. `contact-sheet.jpg` samples eight evenly spaced moments.

## Shared rules worth encoding

1. One idea, one hero object, and one dominant headline per shot.
2. Use a fixed type scale and one accent color per video.
3. Show evidence through a diagram, UI state, number, or comparison—not decoration.
4. Keep layouts stable while the hero object changes state.
5. End with a purpose-built CTA composition rather than adding CTA text to a content scene.
